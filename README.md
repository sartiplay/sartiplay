## ⚙️ About This Unit

I started life cutting metal as a **Polymechaniker EFZ**, then swapped the lathe for a keyboard and never looked back. These days I machine software with the same obsession for tolerances, except the chips are made of TypeScript.

I run **Swiss Web Development Kiefer** (a software studio that builds things that *actually work*), direct cinema through **openiris**, and live somewhere in the overlap between engines, lenses, and edge functions.

```yaml
role:        Fullstack Engineer · Studio Founder
domains:     [ web apps, backends, SaaS, automotive, filmmaking ]
philosophy:  no templates · no filler · no demos that collect dust
disclaimer:  most of my repos are private (sorry, NDAs are a thing 🤐)
```
